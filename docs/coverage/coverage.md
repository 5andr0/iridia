# iridia and dx coverage

Generated by `iridia-coverage table` from the suites in `tools/coverage/suites` at iridia 0.6.0 with dx's d3d9-reader, dxbc-reader, dxil-reader 0.12.0; do not edit by hand.

The table grades iridia's IR path: iridia's IR, by each bytecode's IR lift: iridia-dxbc's (DXBC), iridia-dxil's (DXIL), iridia-d3d9-ir (Direct3D 9); run by iridia-exec on the IR. The WGSL column: iridia-naga's lowering for browsers, read back and validated by naga: information, which decides no run. Each row's reference_status: the lift the IR replaces (DXBC and DXIL lifted into naga modules; a Direct3D 9 program's WGSL read back by naga, its IR drawn again and held to it), run by iridia-exec, until it is removed.

| Group | Meaning |
|---|---|
| pass | it ran and gave what the test expects |
| gap | iridia's to close: it ran and gave something else, or iridia refused or could not run one of its programs |
| runner-limit | the runner does not model something the test needs: pipeline state, an offloader step, a feature a Direct3D 12 device can have and iridia's does not |
| not-applicable | nothing to run on Direct3D: the test is for another API or compiler, Microsoft's compiler refuses its shader, or vkd3d marks that Windows itself reads otherwise |
| expected | a line fails where the test expects Direct3D to fail (XFAIL) |
| unexpected-pass | every line passes where the test expects Direct3D to fail (XPASS, which lit counts as a failure) |
